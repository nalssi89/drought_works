# 권역별 누적강수 현황

기상청 수문기상 가뭄정보 시스템의 66개 대표지점 자료를 이용해 권역별 누적강수량, 1991~2020년 평년값, 평년비를 조회하는 Sites 대시보드입니다.

## 조회 범위

- 기준일 선택과 1개월·3개월·6개월·1년 누적기간
- 12개 권역 및 전국 요약표
- 중부·남부·제주·전국 집계표
- 66개 대표지점 상세표
- 최신 완료일 자동 탐색 및 5분 간격 화면 갱신

기상청 원자료는 통상 14시 이후 갱신되므로, 아직 기준일 자료가 없으면 최근 7일 안의 최신 완료일을 표시합니다.

## 개발 및 검증

```bash
npm install
npm run dev
npm test
npm run lint
npx tsc --noEmit
```

배포 설정은 `.openai/hosting.json`에 있으며, 별도 로컬 서버나 데이터베이스가 필요하지 않습니다.

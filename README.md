# 권역별 누적강수 현황

기상청 수문기상 가뭄정보 시스템의 66개 대표지점 자료를 이용해 권역별 누적강수량, 1991~2020년 평년값, 평년비를 조회하고 미래 가정강수의 영향을 시험하는 Sites 대시보드입니다.

## 조회 및 시나리오 기능

- 기준일 선택과 최근 1개월·3개월·6개월·1년·올해 누적기간
- 완료 일자료 또는 당일 시간관측 기반의 최신 누적강수 현황
- 12개 권역, 중부·남부·제주·전국 집계표
- 10개 권역으로 구분한 66개 대표지점 상세표
- 평년비 65%·55%·45% 이하 셀 색상 표시
- **향후 강수 시나리오**: 미래 특정일까지 10개 권역별 총강수량을 입력해 1·3·6·12개월 및 올해 누적 강수량·평년값·평년비를 재산출
- 기준 대비 강수량·평년값·평년비 증감과 강수부족량 표시

향후 강수량은 완료 일자료 기준일 다음 날부터, 당일 시간자료 기준은 선택 관측시각 이후부터 미래 시점 24시까지 시간상 균등하게 분포한다고 가정합니다. 이동기간 밖으로 빠지는 과거 강수와 평년값은 차감하며, 0 mm 입력은 해당 기간 무강수 시나리오입니다. 이 결과는 예보가 아니라 민감도 분석입니다.

## 자료 갱신

Supabase 예약 작업이 완료 일자료와 당일 시간자료를 수집·계산해 캐시합니다. 화면은 최신 캐시를 읽으며 매시 갱신됩니다. 미래 시나리오 계산에는 기상청 APIHub 일평년값과 과거 공식 범위자료를 추가로 사용합니다.

## 개발 및 검증

```bash
npm install
npm run dev
npm run test:unit
npm run lint
npm run build
```

GitHub Actions는 pull request와 `main` push에서 단위테스트, lint, build를 실행합니다. 배포 설정은 `.openai/hosting.json`에 있으며, Sites 게시 작업은 Work에서 수행합니다.

# 권역별 누적강수 현황

기상청 APIHub의 66개 대표지점 자료를 이용해 권역별 누적강수량, 1991~2020년 평년값, 평년비를 조회하고 미래 가정강수의 영향을 시험하는 Sites 대시보드입니다.

## 조회 및 시나리오 기능

- 기준일 선택과 최근 1개월·3개월·6개월·1년·올해 누적기간
- 완료 일자료 또는 당일 시간관측 기반의 최신 누적강수 현황
- 12개 권역, 중부·남부·제주·전국 집계표
- 10개 권역으로 구분한 66개 대표지점 상세표
- 평년비 65%·55%·45% 이하 셀 색상 표시
- **향후 강수 시나리오**: 미래 특정일까지 10개 권역별 총강수량을 입력해 1·3·6·12개월 및 올해 누적 강수량·평년값·평년비를 재산출
- 기준 대비 강수량·평년값·평년비 증감과 강수부족량 표시

향후 강수량은 완료 일자료 기준일 다음 날부터, 당일 시간자료 기준은 선택 관측시각 이후부터 미래 시점 24시까지 시간상 균등하게 분포한다고 가정합니다. 이동기간 밖으로 빠지는 과거 강수와 평년값은 차감하며, 0 mm 입력은 해당 기간 무강수 시나리오입니다. 이 결과는 예보가 아니라 민감도 분석입니다.

## 자료 갱신

Supabase 예약 작업은 다음 순서로 캐시를 갱신합니다.

- 매일 00:10: 익일 00시 `RN_DAY` 시간자료로 전날의 시간자료 완료값을 생성
- 매일 01:10~23:10: 최신 `RN_DAY` 시간자료로 당일 값을 갱신
- 매일 01:20~23:20: 공식 일자료가 준비될 때까지 매시간 확인하고 전날 완료값을 한 번 교체

시간자료 갱신 때 1·3·6·12개월 전체 일자료를 다시 받지는 않습니다. 직전 완료 캐시에서 새 하루를 더하고 기간 밖으로 빠지는 경계일 하루를 빼는 증분 방식이며, 올해 누적은 새 하루만 더합니다. 공식 교체에는 APIHub `sts_rn.php`의 `RN_DSUM`을 사용합니다. `RN_DSUM=-99.9`와 시간자료 `RN_DAY=-9.0`은 무강수 0.0 mm로 처리하고, 기간 밖으로 빠지는 경계일의 대표지점 행 자체가 없을 때만 익일 00시 시간자료로 보완합니다. 일자료가 준비되지 않은 동안에는 시간자료 완료값을 유지하며, 공식 일자료가 한 번 교체된 뒤에는 같은 날 이후 예약에서 Edge Function과 외부자료를 다시 호출하지 않습니다. 기존 캐시의 자료원이 다르거나 날짜가 연속되지 않으면 `RN_DSUM` 일자료 전체 기간으로 캐시를 다시 생성합니다.

정기 최신 갱신은 위 증분 방식을 사용하지만, 사용자가 과거 기준일이나 미래 시나리오의 임의 기간을 직접 조회할 때는 해당 기간의 `RN_DSUM` 일자료를 최대 31일 단위로 조회해 합산합니다. 강수 관측 자료원은 APIHub 일자료와 시간자료뿐입니다. 평년비 계산에는 APIHub의 1991~2020년 일평년값을 사용합니다.

## 개발 및 검증

```bash
npm install
npm run dev
npm run test:unit
npm run lint
npm run build
```

GitHub Actions는 pull request와 `main` push에서 단위테스트, lint, build를 실행합니다. 배포 설정은 `.openai/hosting.json`에 있으며, Sites 게시 작업은 Work에서 수행합니다.
